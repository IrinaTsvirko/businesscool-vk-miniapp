BUSINESS COOL MINI APP v3.3 — GitHub Pages

Этот архив содержит только публичную клиентскую часть Mini App. Cloudflare Worker и секретные ключи сюда не добавлять.

1. Создайте новый PUBLIC-репозиторий на GitHub с названием businesscool-vk-miniapp. Не используйте действующий репозиторий основного сайта Business Cool.
2. Выберите Add file -> Upload files и загрузите СОДЕРЖИМОЕ распакованной папки в корень репозитория. Не нужно загружать ZIP одним файлом и не нужно создавать вложенную папку с названием пакета.
3. Убедитесь, что index.html находится в корне репозитория, а assets — рядом с ним.
4. Откройте Settings -> Pages -> Build and deployment -> Deploy from a branch; Branch: main; Folder: /(root); Save.
5. GitHub Pages откроет адрес вида https://USERNAME.github.io/businesscool-vk-miniapp/ . Откройте его напрямую в браузере.
6. Только после проверки GitHub Pages вставьте полный URL, включая завершающий слэш, во все три адреса приложения ID 54891534 в VK Developers -> Настройки -> Размещение.
7. Проверьте https://vk.ru/app54891534. Если опять зависает, анализируйте Network/Console: смена хостинга сама по себе не гарантирует исправления.

Внимание: автоматические заявки в Telegram требуют отдельно подключённого Worker v3.3 и правильных событий VK. Не меняйте рабочего бота ради проверки страницы.

Не публикуйте токены VK, TG или секреты Cloudflare в репозитории.
